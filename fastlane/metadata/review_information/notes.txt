로그인이나 계정이 필요 없는 보드게임입니다. 컴퓨터 대전과 한 기기 2인 대전은 네트워크 없이 동작합니다.

온라인 대국은 Game Center 실시간 매치(GKMatchmaker)를 사용합니다. "온라인 대국 > 방 만들기"로 4자리 코드를 만들고, 다른 기기에서 같은 코드로 들어가면 대국이 시작됩니다. 채팅 기능은 없습니다.

No account is required. Single-player and local two-player modes work offline. Online play uses Game Center real-time matches: create a room to get a 4-digit code, and join with the same code on another device. There is no chat.
